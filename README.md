# 💊 Mis Medicamentos a Tiempo

<div align="center">

### Sistema de Apoyo a la Adherencia Terapéutica para Adultos Mayores

Aplicación web diseñada para ayudar a los adultos mayores a gestionar sus tratamientos farmacológicos mediante recordatorios, seguimiento y registro de tomas de medicamentos.

## ✨ Características Principales

✅ Gestión inteligente de medicamentos

✅ Recordatorios visuales y sonoros

✅ Registro de tomas realizadas

✅ Historial y seguimiento de adherencia

✅ Estadísticas de cumplimiento terapéutico

✅ Perfil y preferencias personalizables

✅ Módulo de cuidador autorizado

✅ Diseño accesible para adultos mayores

✅ Interfaz moderna y adaptativa

---

## 🩺 Objetivo del Proyecto

Facilitar el seguimiento de tratamientos farmacológicos, promoviendo la adherencia terapéutica mediante una experiencia sencilla, intuitiva y accesible para personas mayores.

---

## 🚀 Módulos del Sistema

| Módulo | Función |
|----------|----------|
| 🏠 Inicio | Resumen de tomas y acceso rápido |
| 💊 Medicamentos | Gestión de tratamientos |
| ⏰ Alertas | Recordatorios automáticos |
| 📊 Historial | Seguimiento de registros |
| ⚙️ Preferencias | Configuración personalizada |
| 👨‍⚕️ Cuidador | Apoyo y monitoreo autorizado |
| ❓ Ayuda | Información y orientación |
